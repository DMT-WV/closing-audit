점장 오픈·마감 운영 체크업 파일럿

점장님이 오픈·마감 시간대를 직접 근무하면서 해당 시간대의 직원 운영과 매장 상태를 확인하고, 향후 관리기준을 정립하기 위한 7주 파일럿 프로그램임.

1. 운영 개념 및 핵심 방향

운영 방향
점장님이 직접 오픈과 마감 시간대를 체험하면서 오픈 직원 / 마감 직원의 실제 운영상태와 매장 준비·정리 수준을 확인하는 프로그램임. 최초 7주는 점장님이 직접 경험하면서 기준을 세우는 파일럿 기간이며, 이후에는 지정 직원이 정기 체크업을 수행하고 점장님은 자기 지점 관리자로 전환함.

OPENING 오픈 체크업

  • 마켓 오픈시간은 오전 8:30임
  • 오픈 직전·직후 고객을 받을 준비상태 확인
  • 조근인력, POS, 신선식품, 청결, 설비, 진열상태 확인
  • 전날 마감의 미해결 사항이 실제 해결됐는지 확인

CLOSING 마감 체크업

  • 저녁 피크부터 실제 Closing까지 운영 확인
  • 마감 인력배치, 고객응대, 잔여재고, 폐기·보관, 도난·Safety 확인
  • 다음날 Open 가능한 상태인지 확인
  • 미해결 사항은 다음 Opening으로 연결

2. 7주 Dual Rotation

7주파일럿 기간
주 2회Opening 1 + Closing 1
14회점장 1인당 체험

오픈과 마감 사이에 3일 오프셋을 두어 같은 날 겹치지 않도록 설계함. 7주가 끝나면 각 점장님은 Opening 월~일 1회씩 + Closing 월~일 1회씩 모두 경험함.

7주 로테이션 원칙

Opening은 각 점포의 시작요일에서 매주 하루씩 이동하며 순환하고, Closing은 Opening보다 3일 뒤의 요일로 배정함. 이를 통해 7주 동안 Opening과 Closing 모두 월~일을 각각 한 번씩 경험하도록 운영함.
수요일 운영: 기존 수요일 휴무를 원칙으로 하되, 파일럿 중 수요일 Opening 또는 Closing이 배정된 주에는 같은 주 다른 날을 대체휴무로 조정함.

실제 일정 운영

각 주차의 배정요일을 실제 달력 날짜에 연결하여 점장님별 Opening / Closing 일정을 표시함. 주간 일정과 7주 전체 일정에서 동일한 기준으로 확인할 수 있도록 운영함.

8. 7주 파일럿 이후 운영 전환

Phase 1 · 7주

점장 직접 체험
  • Opening 주 1회
  • Closing 주 1회
  • 각 요일 모두 경험
  • 오픈·마감 직원 운영 직접 확인
  • 향후 관리기준 습득
→

Phase 2 · 정규 운영

직원 체크업 + 점장 관리자
  • 지정 직원이 지점코드로 Opening/Closing 체크업
  • 직원은 현장 기록·사진·제출 수행
  • 점장은 자기 지점 관리자모드로 현황·이슈·Follow-up 관리
  • 본사는 6개 지점 통합관리
장기 운영은 Closing → 미해결 사항 → 다음 Opening 확인 → 점장 검토 → Follow-up → 본사 분석 구조로 연결함. 즉 OPEN → OPERATE → CLOSE → PREPARE → OPEN의 연속 운영관리 Cycle을 구축함.
